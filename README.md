# python-learning

Python practice projects completed alongside my Level 7 Diploma in
AI and Working into the Future at CCT College Dublin.

## Projects

### 1. Café receipt
A receipt for a café that adds up the items ordered, works out the VAT
included in the price, and prints a "Thanks, see you soon!" message.

**Concepts practised:** variables, ints vs floats, maths with variables,
f-strings, formatting numbers with `:.2f`, aligning columns.
